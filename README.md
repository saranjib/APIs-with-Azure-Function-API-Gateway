# 🚀 APIs with Azure Functions & Azure API Management

A simple hands-on Azure project demonstrating how to build a **serverless REST API using Azure Functions** and expose it through **Azure API Management (APIM)** as an API Gateway.

The project uses Python Azure Functions to implement a Product API and Azure API Management to provide a managed gateway in front of the serverless backend.

## 🎯 Project Objectives

* Create an HTTP API using Azure Functions.
* Build REST API endpoints using Python.
* Deploy the Function App to Azure.
* Create Azure API Management.
* Publish the Function API through APIM.
* Use APIM as the API Gateway.
* Apply API Management policies.
* Test APIs through the APIM endpoint.
* Provision Azure infrastructure using Terraform.
